# The Physics of Juggling

A juggling-themed physics outreach talk delivered at multiple venues 2014-2015. This branch holds the **only surviving slide deck** — the 1 Jul 2015 iteration prepared for the Senior Physics Challenge at Churchill College, Cambridge.

The slide source is lost; only the rendered PDF survives (recovered from cold-store backup of `appcs:~/public_html/`).

Earlier deliveries used precursor versions of the same talk:
- 10 Feb 2014 — CCPE, Cavendish Laboratory
- 30 Jun 2014 — Senior Physics Challenge, Corpus Christi College
- 5 Oct 2014 — Fun Palaces, Brockwell Lido, London
