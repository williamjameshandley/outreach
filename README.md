# Cosmology

A talk on cosmology delivered at Alleyn's School, London — Will's earliest outreach talk in this repository (taking-back-to-school visit).

The committed PDF is the **original delivered artefact** from September 2012. The source `will_handley.tex` is preserved for the record but uses two custom style files (`presentationtools.sty` and `Alleyns.sty`) that have been lost; the PDF will not rebuild from source. See `williamjameshandley/outreach_legacy` for the original git history.
