# Will Handley's outreach talks

Public-facing astrophysics and cosmology talks given at schools, colleges, public lectures, and cafe-scientifique events. Each talk lives on its own branch — see `CLAUDE.md` for the branch-per-talk layout.

For academic talks see [williamjameshandley/talks](https://github.com/williamjameshandley/talks).
