# The James Webb Telescope

A talk on the James Webb Space Telescope for the Sherrington Society at Gonville & Caius College, Cambridge — given a few months after JWST's first public images.

The source `will_handley.tex` was committed retroactively in Oct 2023 (during overlapping work on the CUPS Hubble-tension talk); the file's internal date macro and accompanying PDF reflect the actual 31 Oct 2022 delivery.
